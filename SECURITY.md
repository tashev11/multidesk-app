# Безопасность

MultiDesk работает с профилями Авито и локальными данными. Безопасность сессий и лицензий критична.

## Что не публикуется

- исходный код коммерческого приложения;
- приватный ключ выпуска лицензий;
- API-ключи ИИ-провайдеров;
- серверные `.env` и платёжные секреты;
- данные пользователей;
- cookies, токены и локальные профили сессий.

## Локальные данные

Каждый профиль работает в собственной Chromium-сессии. Данные сессии хранятся на устройстве пользователя. Для чувствительных данных используются защищённые хранилища ОС, где это применимо.

## Лицензирование и ИИ

Ключи PRO проверяются по публичному криптографическому ключу. Приватный мастер-ключ в сборку не встраивается.

Запросы ИИ-копилота идут через серверный контур MultiDesk. Секретный API-ключ модели в desktop-приложении не хранится.

## Как сообщить об уязвимости

Не публикуйте в открытом Issue уязвимость, если она может дать доступ к чужим данным, сессиям или обход лицензии.

Для обычных ошибок: [открыть Issue](https://github.com/tashev11/multidesk-app/issues/new/choose).

Для критической уязвимости напишите владельцу репозитория напрямую и укажите:

1. версию MultiDesk;
2. ОС;
3. описание;
4. шаги воспроизведения;
5. возможный ущерб.

Просим не использовать найденную уязвимость для доступа к чужим аккаунтам или обхода оплаты.
