# Безопасность MultiDesk

MultiDesk — desktop-приложение, которое работает с пользовательскими профилями Авито и локальными данными. Безопасность сессий, лицензий и серверных секретов для проекта критична.

## Что не публикуется

В публичном репозитории `multidesk-app` не размещаются:

- исходный код коммерческого приложения;
- приватный ключ выпуска лицензий;
- API-ключи ИИ-провайдеров;
- серверные `.env` и платёжные секреты;
- данные пользователей и покупателей;
- локальные профили, cookies и токены авторизации.

## Локальные данные

Каждый профиль Авито работает в собственной Chromium-сессии. Данные сессии хранятся локально на устройстве пользователя.

Для чувствительных локальных данных приложение использует или должно использовать защищённые механизмы операционной системы, включая системные хранилища ключей Windows/macOS там, где это применимо.

## Лицензирование

Лицензионные ключи проверяются по публичному криптографическому ключу. Приватный мастер-ключ выпуска лицензий не встраивается в приложение и не распространяется среди пользователей.

## ИИ-копилот

Секретный API-ключ модели не должен находиться в desktop-сборке. Запросы к ИИ проходят через серверный контур MultiDesk.

## Сообщить об уязвимости

Не публикуйте потенциально опасную уязвимость в открытом Issue, если она может раскрыть секреты, дать доступ к чужим данным или позволить обход лицензирования.

Для обычных ошибок интерфейса и функциональности используйте GitHub Issues:

https://github.com/tashev11/multidesk-app/issues

Для критической уязвимости свяжитесь с владельцем проекта напрямую и приложите:

- версию MultiDesk;
- операционную систему;
- описание проблемы;
- шаги воспроизведения;
- оценку возможного воздействия.

## Ответственное раскрытие

Просим не использовать найденную уязвимость для доступа к чужим аккаунтам, данным или обхода оплаты. После подтверждения проблемы мы постараемся исправить её до публичного раскрытия деталей.
