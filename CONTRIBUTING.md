# Как помочь проекту

Исходный код MultiDesk приватный. Публичный вклад — это отчёты об ошибках, идеи и уточнения документации.

## Ошибка

1. Проверьте [Issues](https://github.com/tashev11/multidesk-app/issues), нет ли уже такой задачи.
2. Создайте Issue по шаблону «Ошибка».
3. Укажите версию, ОС и шаги.
4. Не прикрепляйте секреты.

## Идея

Опишите рабочую задачу, а не только кнопку. Пример: «агентству нужен PDF-отчёт клиенту раз в неделю».

## Pull Request

PR в этот репозиторий принимаются только для публичной документации: опечатки, ясность, мёртвые ссылки.
