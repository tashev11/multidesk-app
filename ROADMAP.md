# Roadmap MultiDesk

Публичный план развития. Приоритеты могут меняться по обратной связи пользователей и изменениям платформы Авито.

## Сейчас

- несколько профилей Авито в одном окне;
- изолированные Chromium-сессии;
- аналитика рынка и конкурентов;
- позиции и поисковые подсказки;
- локальная история и динамика;
- Excel-экспорт;
- XML для автозагрузки;
- ИИ-копилот;
- пробный период и PRO-лицензии;
- сборки для Windows и macOS.

## Ближайшие задачи

- стабильная публичная доставка `.exe` и `.dmg` через GitHub Releases;
- автоматическая проверка новой версии;
- улучшение первого запуска и подключения профиля;
- понятные статусы капчи, ограничений и ошибок загрузки;
- расширение аналитических подсказок;
- улучшение сравнения объявлений и конкурентов;
- экспорт дополнительных отчётов;
- улучшение журнала изменений внутри приложения.

## Далее

- командный режим и разграничение ролей;
- синхронизация настроек между устройствами без передачи браузерных секретов;
- дополнительные шаблоны отчётов;
- расширенная работа с массовыми объявлениями;
- интеграции с внешними CRM и сервисами;
- публичная документация для корпоративного использования.

## Предложить функцию

Если вам не хватает конкретной возможности, создайте Feature Request:

https://github.com/tashev11/multidesk-app/issues/new/choose

Лучшие предложения — те, где описано не только «что добавить», но и какую рабочую задачу это должно решать.
