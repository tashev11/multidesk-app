## Зачем это нужно

Если вы ведёте несколько профилей Авито, обычный браузер превращается в набор вкладок, профилей Chrome и ручных таблиц.

**MultiDesk** собирает повседневную работу в одно локальное приложение:

- переключение между аккаунтами без смены браузерных профилей;
- изолированная Chromium-сессия на каждый профиль;
- аналитика рынка, конкурентов и позиций;
- экспорт в Excel и подготовка XML;
- ИИ-помощник для текстов объявлений.

Это не облачный кабинет «поверх Авито» и не официальный продукт площадки. Это отдельное рабочее место продавца, авитолога или агентства.

## Возможности

| Модуль | Что даёт |
|---|---|
| Профили Авито | Быстрое переключение между аккаунтами в одном окне |
| Изолированные сессии | У каждого профиля свои cookies, localStorage и авторизация |
| Анализ рынка | Цены, выборка, доставка, продвижение, частые слова, динамика |
| Конкуренты | Карточки объявлений, цены, города и изменения показателей |
| Позиции | Проверка позиции объявления по запросу |
| Поисковые подсказки | Живые формулировки запросов Авито |
| Overlay | Дополнительные метрики прямо на странице поиска |
| Своя статистика | Показы, контакты, конверсия и сравнение объявлений |
| Экспорт | Выгрузка в Excel |
| Автозагрузка | Подготовка XML для массовой работы |
| ИИ-копилот | Заголовки, описания и правки объявлений |
| Локальная история | Снапшоты и динамика хранятся на компьютере пользователя |

> Некоторые показатели зависят от того, что Авито показывает конкретному профилю, категории и региону.

## Как это работает

```text
1. Добавляете профиль в MultiDesk
2. Входите в Авито обычным способом
3. Приложение сохраняет отдельную сессию
4. Добавляете следующие профили
5. Переключаетесь из бокового меню
6. Смотрите аналитику, экспорт и ИИ в том же окне
```

## Частые вопросы

<details>
<summary><b>Исходный код открыт?</b></summary>

Нет. Этот репозиторий — официальная витрина, канал релизов и поддержки. Исходный код коммерческого приложения хранится в приватном репозитории.
</details>

<details>
<summary><b>Нужно ли каждый раз входить в Авито?</b></summary>

Обычно нет. У каждого профиля своя сохраняемая сессия. Повторный вход нужен, если площадка завершит сессию или запросит проверку.
</details>

<details>
<summary><b>Храните ли вы пароли Авито на сервере?</b></summary>

Нет. Архитектура рассчитана на локальную работу с профилями. Чувствительные данные должны храниться через защищённые механизмы ОС.
</details>

<details>
<summary><b>Можно пользоваться без PRO?</b></summary>

Да, в рамках пробного периода. Дальше набор возможностей зависит от тарифа и версии.
</details>
