# MultiDesk

### Рабочее место авитолога в одном окне

**Несколько аккаунтов Авито · аналитика ниши и конкурентов · позиции · Excel/XML · ИИ-копилот**

MultiDesk — программа для авитолога, продавца и агентства: помогает работать с несколькими профилями Авито, анализировать объявления и конкурентов и меньше переключаться между браузерами и таблицами.

## Что решает MultiDesk

Если вы ведёте несколько профилей Авито, обычный браузер быстро превращается в десятки вкладок, разные профили Chrome и ручные таблицы.

<table>
<tr>
<td width="33%" valign="top"><h3>👥 Несколько аккаунтов</h3><p>Каждый профиль Авито работает в своей отдельной Chromium-сессии. Переключение — из одного интерфейса.</p></td>
<td width="33%" valign="top"><h3>📊 Аналитика Авито</h3><p>Ниша, конкуренты, цены, позиции, поисковые формулировки, своя статистика и история изменений.</p></td>
<td width="33%" valign="top"><h3>✨ Инструменты авитолога</h3><p>Excel, XML Автозагрузки, мониторинг и ИИ-помощник для заголовков и описаний объявлений.</p></td>
</tr>
</table>

**MultiDesk не заменяет Авито — он собирает ежедневную работу вокруг него в одно desktop-приложение.**

## 🚀 Возможности

| | Возможность | Что даёт |
|---|---|---|
| 👤 | **Профили Авито** | Несколько аккаунтов в одном окне без постоянной смены профилей браузера |
| 🔒 | **Изолированные сессии** | У каждого профиля свои cookies, localStorage и авторизация |
| 📈 | **Анализ рынка** | Цены, выборка, доставка, продвижение, частые слова и динамика |
| 🕵️ | **Анализ конкурентов** | Объявления, цены, города, продвижение и изменения показателей |
| 🎯 | **Контроль позиций** | Проверка позиции объявления по поисковому запросу |
| 🔎 | **Поисковые подсказки** | Живые формулировки запросов Авито для подбора ключевых слов |
| 📋 | **Своя статистика** | Показы, контакты, избранное, конверсия и сравнение объявлений там, где данные доступны |
| 🖥️ | **Overlay** | Дополнительная аналитика прямо поверх страницы поиска |
| 📗 | **Excel** | Выгрузка собранных данных в таблицу |
| 📦 | **XML Автозагрузки** | Подготовка XML для массовой работы с объявлениями |
| 🤖 | **ИИ-копилот** | Помощь с заголовками, описаниями и улучшением объявлений* |
| 🕒 | **Локальная история** | Снапшоты и динамика сохраняются на компьютере пользователя |

> *ИИ-копилот требует активной лицензии и подключения к серверу MultiDesk. Некоторые аналитические показатели зависят от того, какие данные Авито показывает конкретному профилю, категории и региону.

## 🔑 Лицензия

При первом запуске доступен **14-дневный пробный период**.

После него PRO-функции открываются лицензионным ключом с криптографической подписью. Проверка лицензии выполняется локально; приватный ключ выпуска лицензий пользователям не передаётся.

## 🔐 Приватность и безопасность

- профили работают в отдельных Chromium-сессиях;
- история аналитики хранится локально;
- API-ключ ИИ-модели не встраивается в приложение;
- исходный код коммерческого приложения остаётся приватным;
- серверные секреты и приватный ключ лицензирования не публикуются в этом репозитории.

## ❓ Частые вопросы

<details>
<summary><b>Это официальный продукт Авито?</b></summary>

Нет. MultiDesk — независимое программное обеспечение и не является продуктом или подразделением Авито.
</details>

<details>
<summary><b>Исходный код открыт?</b></summary>

Нет. Этот репозиторий — официальная публичная витрина, канал релизов и поддержки. Исходный код коммерческого приложения хранится в приватном репозитории.
</details>

<details>
<summary><b>Нужно ли каждый раз входить в Авито?</b></summary>

Обычно нет. Каждый профиль использует собственную сохраняемую сессию. Повторный вход понадобится, если сама площадка завершит сессию или запросит повторную авторизацию.
</details>

<details>
<summary><b>MultiDesk хранит пароли Авито на сервере?</b></summary>

Нет. Архитектура приложения рассчитана на локальную работу с профилями. Сервер MultiDesk не используется как хранилище паролей Авито.
</details>

<details>
<summary><b>ИИ-копилот работает в пробном периоде?</b></summary>

ИИ-копилот требует активированной лицензии и подключения к серверу MultiDesk. Остальные доступные функции пробного периода определяются текущей версией приложения.
</details>

## 🔍 Аналитика Авито и инструменты для авитолога

MultiDesk объединяет задачи, для которых обычно ищут отдельные решения: **сервис для авитолога**, **программа для работы с Авито**, **аналитика Авито**, **анализ конкурентов на Авито**, **анализ ниши**, **контроль позиций объявлений**, **подбор поисковых запросов**, **мультиаккаунт Авито**, **Excel-аналитика** и **XML Автозагрузка**.

Это помогает находить MultiDesk по релевантным запросам без искусственного списка ключевых слов.
